# Modelos de Datos - Interfaces TypeScript (Frontend) 📦

Este directorio centraliza las interfaces de tipado estático utilizadas a lo largo de la aplicación Angular.

## 📂 Archivos Principales

- [**usuario.model.ts**](./usuario.model.ts): Define la estructura de datos del usuario, sus roles y sus asignaturas aprobadas.
- [**curso.model.ts**](./curso.model.ts): Estructura del curso, ciclo académico e indicadores de prerequisitos.
- [**asesoria.model.ts**](./asesoria.model.ts): Define la relación, fecha, hora, estado, enlaces de Meet y comentarios de una cita de asesoría académica.
- [**rol.model.ts**](./rol.model.ts): Estructura de mapeo de privilegios de usuario.
- [**index.ts**](./index.ts): Archivo de exportación barril para importar múltiples modelos desde una sola ruta limpia.
