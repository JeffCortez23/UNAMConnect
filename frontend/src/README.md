# Código Fuente Principal (Frontend) 💻

Este directorio es el núcleo de la aplicación Angular. Aquí se encuentra todo el código que se compila y empaqueta para generar la interfaz de usuario de UNAMConnect.

## 📁 Estructura Principal

- [**/app**](./app): Contiene los componentes, servicios y módulos.
- `index.html`: El archivo HTML principal que sirve como contenedor de la SPA.
- `main.ts`: Punto de entrada de TypeScript que arranca la aplicación.
- `styles.scss`: Estilos globales de la aplicación utilizando Sass.

## 🛠️ Desarrollo
Para añadir nuevas funcionalidades, generalmente trabajarás dentro de la subcarpeta `app`, siguiendo las convenciones de Angular para la creación de componentes y servicios.
