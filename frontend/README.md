# UNAMConnect - Frontend 🎨

Este directorio contiene la aplicación cliente desarrollada con Angular 17/18. Es la interfaz de usuario que interactúa con el backend para ofrecer una experiencia fluida a estudiantes y tutores.

## 📂 Estructura del Frontend

- [**/public**](./public): Contiene activos estáticos como imágenes, iconos y el archivo `favicon.ico`.
- [**/src**](./src): Contiene el código fuente principal de la aplicación.
  - [**/app**](./src/app): Lógica de componentes, servicios, modelos y módulos de Angular.
- `angular.json`: Configuración del CLI de Angular para el proyecto.
- `package.json`: Dependencias y scripts del frontend.
- `tsconfig.json`: Configuración de TypeScript.

## 🛠️ Tecnologías Utilizadas
- **Angular**: Framework principal para el desarrollo de la SPA.
- **TypeScript**: Lenguaje de programación base.
- **Sass (SCSS)**: Preprocesador de CSS para estilos avanzados.
- **RxJS**: Gestión de flujos de datos asíncronos y eventos.

## 📦 Instalación y Uso
1. Entrar a la carpeta: `cd frontend`
2. Instalar dependencias: `npm install`
3. Ejecutar el servidor de desarrollo: `npm start` o `ng serve`
4. Abrir en el navegador: `http://localhost:4200`

## 📅 Estado Actual
El frontend se encuentra actualmente en su **estado inicial (vacío)**. Solo contiene la estructura base generada por el CLI de Angular, sin lógica de componentes, servicios ni integración con el API REST.
